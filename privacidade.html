Política de Privacidade

Esta política descreve como as informações são tratadas no Laboratório de Tabela Hash.

1. Coleta de Dados

Este simulador é uma aplicação executada inteiramente no lado do cliente (no seu navegador). Não coletamos, armazenamos ou transmitimos quaisquer dados inseridos no simulador para servidores externos.

2. Uso de Cookies e Armazenamento

Não utilizamos cookies para rastreamento de usuários ou publicidade. Qualquer uso de tecnologias de armazenamento local pelo navegador ocorre estritamente para manter o estado ou as preferências locais durante o uso da aplicação.

3. Compartilhamento de Informações

Como não coletamos dados pessoais nem armazenamos informações do usuário, não há compartilhamento de informações com terceiros.

4. Alterações na Política

Reservamo-nos o direito de modificar esta política de privacidade a qualquer momento, para refletir as atualizações no sistema ou alterações regulatórias.
